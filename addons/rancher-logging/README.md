# rancher-logging

Collects cluster, host and audit logs and routes them to user-configured log
servers, based on the rancher-logging chart with Harvester-specific defaults
(RKE2/kube-audit sources and the Harvester event tailer).

- Stage: **GA**
- Built-in: **yes** (shipped in the ISO, disabled by default)

Documentation: https://docs.harvesterhci.io/latest/monitoring/logging

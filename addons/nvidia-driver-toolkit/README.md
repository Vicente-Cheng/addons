# nvidia-driver-toolkit

Installs and manages the NVIDIA vGPU KVM driver on Harvester hosts; required
for vGPU support together with the pcidevices-controller addon. The driver
location must be configured to a user-provided HTTP endpoint.

- Stage: **GA**
- Built-in: **yes** (shipped in the ISO, disabled by default)

Documentation: https://docs.harvesterhci.io/latest/advanced/addons/nvidiadrivertoolkit
